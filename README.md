# И так сойдёт — frontend

Клиентская часть проекта на React 18 и Vite.

## Требования

- Node.js 20.19 или новее
- npm 10 или новее

## Команды

```bash
npm install
npm start
npm run build
npm run preview
npm test
npm run lint
npm run lint:styles
```

Development-сервер запускается на `http://localhost:3000`. Production-сборка
создаётся в папке `build`, которую может раздавать backend.

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните значения. Новые переменные
используют префикс `VITE_`. Для совместимости во время перехода также читаются
старые переменные с префиксом `REACT_APP_`.

## Плавная прокрутка на десктопе

Lenis загружается отдельным чанком только при ширине от 1200 px, наличии
точного указателя и поддержки наведения. При `prefers-reduced-motion: reduce`
прокрутка остаётся нативной. Настройки в `src/config/desktopScroll.js`:
инерция 0,8 секунды и коэффициент колеса 75/120 из примера дизайнера.

Плавность применяется только к дискретным вертикальным событиям колеса.
У браузера нет точного признака «мышь или тачпад», поэтому мелкие пиксельные
жесты, горизонтальная прокрутка, масштабирование, touch-события и клавиатура
сохраняют нативное поведение. Формы, модалки и вложенные области прокрутки
также не перехватываются. Открытие модалки останавливает инерцию, а смена
маршрута, брейкпоинта или настройки уменьшения движения очищает экземпляр.
