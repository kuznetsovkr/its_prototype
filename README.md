# И так сойдёт — frontend

Клиентская часть проекта на React 18 и Vite.

## Требования

- Node.js 20.19 или новее
- npm 10 или новее

## Команды

```bash
npm install
npm start
npm run build
npm run preview
npm test
npm run lint
npm run lint:styles
```

Development-сервер запускается на `http://localhost:3000`. Production-сборка
создаётся в папке `build`, которую может раздавать backend.

## Переменные окружения

Скопируйте `.env.example` в `.env.local` и заполните значения. Новые переменные
используют префикс `VITE_`. Для совместимости во время перехода также читаются
старые переменные с префиксом `REACT_APP_`.

## Плавная прокрутка на десктопе

Lenis загружается отдельным чанком только при ширине от 1200 px, наличии
точного указателя и поддержки наведения. При `prefers-reduced-motion: reduce`
прокрутка остаётся нативной. Настройки в `src/config/desktopScroll.js`:
инерция 0,8 секунды и коэффициент колеса 75/120 из примера дизайнера.

Плавность применяется только к дискретным вертикальным событиям колеса.
У браузера нет точного признака «мышь или тачпад», поэтому мелкие пиксельные
жесты, горизонтальная прокрутка, масштабирование, touch-события и клавиатура
сохраняют нативное поведение. Формы, модалки и вложенные области прокрутки
также не перехватываются. Открытие модалки останавливает инерцию, а смена
маршрута, брейкпоинта или настройки уменьшения движения очищает экземпляр.

## Автоскейл компактных макетов

Главная, конструктор, сертификат и общие шапка/футер масштабируются от макета 320 px
на ширинах 320–639 px и от макета 640 px на ширинах 640–1199 px. С 1200 px
действует прежняя десктопная вёрстка. Для экранов уже 320 px уменьшение
масштаба отключено, чтобы не уменьшать текст и элементы управления.

Общая Sass-функция `scale.px(число)` из `base/compactScale` переводит размеры
макета в CSS-единицы через `--compact-layout-pixel`. Миксин `scale.container`
задаёт единицу только на нужном компоненте; остальные страницы и модалки
не получают глобальный zoom/transform. Умножаются размеры, шрифты, отступы,
радиусы и расстояния перемещения в анимациях, но не длительности анимаций
и не расстояния scroll-driven эффектов в реальных пикселях прокрутки.

Меню и подложки модалок остаются привязанными к настоящему окну. Сохраняются
нативные жесты, браузерный зум и `prefers-reduced-motion`. Размеры этапов заказа,
изображения, инструкции и форма сертификата используют ту же единицу макета.
Окна таблицы размеров, примеров работ и СДЭК/ручного адреса не масштабируются
вместе со страницей: карта и наложения используют настоящие координаты окна.

Для текстовых полей `scale.control-font(число)` сохраняет размер из макета
в `--mobile-control-font-size`. Последний мобильный safeguard применяет
`max(16px, ...)`: текст может увеличиваться, но никогда не уменьшается ниже
16 px на телефонах и touch-устройствах, чтобы Safari не зумил страницу.
