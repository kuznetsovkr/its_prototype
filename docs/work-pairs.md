Сохранены существующие размеры сетки, кнопки и scroll-zoom; мобильная раскрытая
сетка стала выше, чтобы разместить три ранее отсутствовавшие работы.

Поведение:

- Мышь с поддержкой hover: исходное фото при наведении, вышивка при уходе
  указателя. В сенсорном режиме совместимые мышиные события не запускают hover.
- Touch / pen: нажатие переключает изображение, повторное возвращает вышивку.
- Клавиатура: native button, Enter / пробел переключают; Escape / потеря фокуса
  возвращают вышивку. Состояние озвучивается через `aria-pressed`, загрузка —
  через `aria-busy`.
- Фото запрашивается только при первом взаимодействии. До успешной загрузки
  и декодирования остаётся видна вышивка. При ошибке она также не исчезает,
  следующее взаимодействие позволяет повторить загрузку.
- Изображения кадрируются через `object-fit: cover`, без растягивания. В широких
  карточках это может отсечь часть вертикального исходника, в отличие от
  растянутой фотографии в референсном коде Figma. Для ретривера кадр смещён
  вверх, чтобы не потерять мордочку. Для мобильных ячеек также скорректирован
  кадр корги с мячом и добермана, чтобы сохранить головы в узкой / широкой области.
- При `prefers-reduced-motion` плавная смена отключена, как и прежний scroll-zoom.

Декоративные элементы заголовка оставлены из текущей реализации; галерея
не меняет конструкторный pop-up «Примеры работ».
