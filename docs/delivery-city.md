# Город получения

## Сценарий

1. На этапе получателя пользователь вводит город/населённый пункт и явно выбирает подсказку. Произвольный текст не считается выбором; одноимённые пункты различаются по региону.
2. После выбора доступны способы получения. Самовывоз показывается только для Красноярска, не для других населённых пунктов края.
3. Карта СДЭК получает координаты выбора. Существующая загрузка ПВЗ по видимой области сохранена, весь каталог не загружается.
4. Если на карте выбран ПВЗ другого города, сервер заново получает ПВЗ у СДЭК; город формы обновляется с пояснением. До подтверждения новый заказ не отправляется.
5. Редактирование города сразу сбрасывает ПВЗ, стоимость и расчёт доставки, ручной адрес и отделение Почты. Устаревшие ответы отменяются и не перезаписывают новый выбор.
6. Подтверждённый выбор сохраняется вместе с черновиком. Через 30 дней его нужно подтвердить заново. Уже созданную оплату можно продолжить без повторного выбора города: её доставка неизменяема.

Клавиатура: стрелки выбирают подсказку, Enter подтверждает, Escape закрывает список. Поле на телефоне не меньше 16 px.

## Границы

- Это не возврат прежнего произвольного поля: город подтверждается сервером. Новые таблицы/миграции не нужны.
- Почта и самовывоз пока остаются заявками менеджеру, без выдуманных тарифов. Корзина с несколькими изделиями по-прежнему оплачивается только с СДЭК.
- Подсказки используют серверные `/api/delivery/cities/suggest`, `/resolve`, `/office`. При недоступности сервиса выводится ошибка; текстовый ввод не принимается молча.
- **До деплоя:** в окружении backend нужен `DADATA_API_KEY` (токен API «Подсказки»). Можно использовать существующий токен DaData для адресов; значение не коммитить. Клиенту ключ нового API не передаётся.

## Проверки

`npm test`, `npm run lint`, `npm run lint:styles`, `npm run build`.

`npm run test:e2e:completion` включает `e2e/delivery-city.e2e.js`: пустой город, опечатка/явный выбор, клавиатура, самовывоз, восстановление, координаты карты, другой город ПВЗ, сброс цены, отказ подсказок и запоздавший ответ. API и внешний SDK в этих тестах подменены: это не проверка живых DaData/Яндекс/СДЭК.
